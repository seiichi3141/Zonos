# プロダクトコンテキスト

## なぜこのプロジェクトが存在するのか

### 問題の背景

従来の TTS（Text-to-Speech）システムでは、特定の個人の音声特徴を高品質で再現することが困難でした。特に日本語話者の声質、話し方、感情表現を自然に再現するには高度な技術と大量のデータが必要でした。

### 解決したい課題

1. **音声の個性化**

   - 安野たかひろ氏の特徴的な話し方を再現
   - 自然な日本語の発音とイントネーション
   - 感情や文脈に応じた音声表現

2. **技術的アクセシビリティ**

   - 高品質な TTS 技術の民主化
   - オープンソースモデルの活用
   - 研究・教育目的での利用促進

3. **実用性の向上**
   - 長文テキストの効率的な音声化
   - リアルタイムでの生成・配信
   - 直感的なインターフェース

## このシステムが提供する価値

### 主要機能

1. **高品質音声合成**

   - Zonos-v0.1 による最先端の音声品質
   - 数秒の参照音声から話者特徴を学習
   - 44kHz ネイティブ出力による高音質

2. **柔軟な制御オプション**

   - 話速調整（10-30 フォネーム/分）
   - ピッチ変動制御（20-400 の標準偏差）
   - 8 段階の感情制御（幸福、悲しみ、恐怖、怒り等）
   - 音声品質と DNSMOS スコア調整

3. **実用的なワークフロー**
   - API 経由での自動化対応
   - ストリーミング進捗表示
   - OpenAI API による自然な文章分割
   - 一時ファイル管理とクリーンアップ

### ユーザー体験の目標

1. **シンプルな操作**

   - テキスト入力だけで高品質音声を生成
   - デフォルト設定で即座に利用可能
   - 必要に応じた詳細パラメータ調整

2. **レスポンシブな体験**

   - リアルタイム進捗表示
   - 音声プレビュー機能
   - エラー時の明確なフィードバック

3. **継続的な改善**
   - キャッシュによる高速化
   - 設定の永続化
   - 使用統計とパフォーマンス監視

## どのように機能するべきか

### アーキテクチャ概要

1. **テキスト前処理**

   - eSpeak-ng による音素化
   - 日本語テキストの正規化
   - 長文の自然な分割（OpenAI API 使用）

2. **話者エンベディング**

   - ResNet293 ベースの話者認識モデル
   - LDA 変換による 128 次元エンベディング
   - キャッシュによる高速化

3. **音声生成**

   - Transformer またはハイブリッドバックボーン
   - DAC オートエンコーダーによるデコード
   - CFG（Classifier-Free Guidance）による品質向上

4. **配信とインターフェース**
   - FastAPI による RESTful API
   - Next.js + Material-UI フロントエンド
   - ストリーミング対応とファイル配信

### ワークフロー

1. **ユーザーフロー**

   ```
   テキスト入力 → パラメータ調整 → 音声生成 → プレビュー → ダウンロード
   ```

2. **システム処理フロー**

   ```
   テキスト受信 → 前処理・分割 → 条件付け → モデル推論 → 後処理 → 配信
   ```

3. **キャッシュ戦略**
   ```
   話者エンベディング → メモリ内キャッシュ → ディスク永続化
   モデルファイル → Hugging Face キャッシュ → ローカル保存
   ```
