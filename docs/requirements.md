# Zonos プロジェクト要件

## プロジェクト概要

このプロジェクトは、Zonos-v0.1（Zyphra 社製のオープンソース音声合成モデル）を活用して、特定の話者（安野たかひろ）の音声でテキストを音声化するシステムです。

## 主要目標

### 機能要件

1. **音声合成機能**

   - テキストから自然な日本語音声を生成
   - 特定話者（安野たかひろ）の音声特徴を再現
   - 話速、ピッチ、感情表現の制御
   - ストリーミングでの進捗表示機能

2. **API 提供**

   - RESTful API 経由での音声合成サービス
   - 同期・非同期両対応
   - 長文テキストの自動分割機能（OpenAI API 活用）
   - ファイルダウンロード機能

3. **Web インターフェース**

   - React/Next.js + Material-UI によるフロントエンド
   - 直感的なユーザーインターフェース
   - リアルタイム音声プレビュー

4. **キャッシュシステム**
   - スピーカーエンベディングの永続化
   - Hugging Face モデルキャッシュの活用
   - 高速な再読み込み

### 非機能要件

1. **パフォーマンス**

   - RTX 4090 で約 2 倍速のリアルタイム生成
   - 6GB 以上の VRAM 要求
   - CPU でも動作（ただし低速）

2. **スケーラビリティ**

   - Docker コンテナ化
   - FastAPI による非同期処理
   - 一時ファイルの自動クリーンアップ

3. **メンテナンス性**
   - モジュラー設計
   - 包括的なロギング
   - 設定の外部化（環境変数）

## 技術的制約

1. **ハードウェア要件**

   - NVIDIA GPU（6GB+ VRAM 推奨）
   - Ubuntu 22.04/24.04 または macOS
   - Hybrid モデルは RTX 3000 シリーズ以降が必要

2. **システム依存関係**
   - eSpeak-ng（音素化ライブラリ）
   - CUDA 12.4 対応の PyTorch
   - Python 3.10 以上

## リスク要因

1. **モデル依存性**

   - Hugging Face サービスの可用性
   - Zyphra 社のモデル更新への対応
   - GPU 資源の制約

2. **音声品質**

   - 話者特徴の再現精度
   - 長文での品質維持
   - 感情表現の自然さ

3. **法的・倫理的考慮**
   - 音声合成の悪用防止
   - 話者の同意・権利保護
   - データプライバシー

## 成功指標

1. **技術指標**

   - 音声生成速度：2 倍速以上
   - 応答時間：10 秒以内（短文）
   - 音声品質：自然性 4.0/5.0 以上

2. **機能指標**

   - API 稼働率：99%以上
   - キャッシュヒット率：80%以上
   - エラー率：1%未満

3. **ユーザビリティ指標**
   - Web インターフェースの応答性
   - 直感的な操作性
   - エラーメッセージの明確性

## 範囲外

- リアルタイム音声変換
- 複数話者の音声合成
- 音声認識機能
- 商用利用での大規模展開（個人・研究用途中心）
